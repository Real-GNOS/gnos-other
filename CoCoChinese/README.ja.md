## 技術スタック
- バックエンドフレームワーク: Express 4.x
- テンプレートエンジン: EJS 3.x
- データベース: MongoDB >=7.x
- パッケージマネージャー: npm 9.x

## クイックスタート
```bash
# 依存関係をインストール
npm install

# 開発モードで起動(ホットリロード付き)
npm run dev

# 本番モードで起動
npm start

# データベース初期化
node scripts/initDB.js
```

## プロジェクト構造(MVCアーキテクチャ)
```
├── app.js         # アプリケーションエントリ
├── models/        # データモデル(M)
├── routes/        # ルートコントローラー(C)
├── views/         # ビューテンプレート(V)
├── public/        # 静的リソース
├── scripts/       # データベース移行スクリプト
└── config/        # 環境設定
```

## 環境設定
.envファイルを作成:
```ini
PORT=3000
MONGODB_URI=mongodb://localhost:27017/cocokalo
SESSION_SECRET=your_session_secret
```
